## Troubleshooting Guide

### Minecraft fails to open

Check that Minecraft is installed and that the browser can open the associated application. Close unrelated browser prompts, then try the launch control again.

### The launcher page will not load

Verify the browser's network connection and reload the hosted page. If it still fails, test another supported browser or work from a local copy of the project.

### Launching is blocked by the browser

Opening an external application may require explicit confirmation in some browsers. Examine the prompt and permit the action only when it corresponds to what you intended to do.

### The local version does not function

Make sure the entire repository was downloaded and that the HTML files remain together with their required assets. Serving the project from a local web server may also avoid restrictions imposed on local files.

### The latest changes are missing

Reload the hosted page and clear its browser cache. Separately downloaded copies must be refreshed by obtaining the newer project files.

### Must I install a desktop launcher?

Abrir Minecraft is classified as a web launcher and uses a browser-driven process. The Minecraft installation still needs to be present on the device for the opening action to be useful.

### Will it update Minecraft files on my device?

No local update mechanism is specified. The hosted launcher page and downloaded project files are updated separately.

### Can the project be used locally?

Yes. Clone or download the repository and open its HTML content locally, while keeping in mind that browser restrictions may apply to local files.

### Does the project support rollback?

No automatic rollback feature is specified. For an older local version, preserve or restore an earlier copy of the repository files.

### Where are logs stored?

Abrir Minecraft does not define a dedicated logging system. For problems occurring in the browser, inspect the developer console and any launch or permission messages shown there.

### What platforms are supported?

The project is identified as a Web platform utility. Its actual operation depends on the browser, device permissions, and the Minecraft environment installed on the device.
